About the product

What is KhAter?

KhAter is a browser-based workbook for technical review and practice in Persian and Arabic type design. It helps users enter or inspect font metrics, review glyphs and spacing, organize practice data, and create design references.

Who is it for?

KhAter is intended for type designers, students, and learners working with Persian or Arabic letterforms, especially when they need metric guides, glyph-form notes, or printable practice sheets.

What can it do?

  • Enter or extract font metrics such as UPM, Ascender, and Descender.
  • Inspect glyphs, advance widths, and available kerning information.
  • Manage character and practice data with Excel workbooks.
  • Create SVG and PNG references and print practice workbooks to PDF from the browser.

How to use it and licensing

For normal use, open the app in a modern browser with JavaScript enabled; no desktop installation or account is required. File processing runs client-side in the browser. The source code is MIT licensed, while artwork and generated outputs are licensed under CC BY-NC 4.0. Local development requires Node.js and pnpm; see the repository README for setup instructions.
